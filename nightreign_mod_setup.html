Nightreign Mod Setup

Seamless Co-op plus More Map Variations. Same Nightfarers, same relics, a much bigger pool of things that want you dead. Set it up once with one script, then every session is one double-click. Your normal game stays untouched: launch from Steam like always and you're playing vanilla.

New night bosses include Malenia, Radahn, Maliketh, Godfrey, Messmer, Midra, Rellana, Rennala, Gael and Manus. Fortissax replaces Ancient Dragon. Seamless Co-op also unlocks every Everdark boss and Deep of Night without FromSoftware's servers, so we can run Deep of Night together.

RelicsAnything earned in modded runs lands in the Seamless save, not your normal one. Deep of Night relics farmed here won't show up in vanilla. Depth and rank tracking under Seamless is unconfirmed until we try it.

Balance stays close to vanilla: the mod team rebalances rune rewards and HP for every added enemy. No god mode, no stat changes to Nightfarers or relics.

One ruleNever take the modded game into vanilla online matchmaking. Seamless keeps you off FromSoftware's servers on purpose. Launch from Steam normally whenever you want vanilla.

Once per PC · about 10 minutesSetup

1

Install ModEngine 3

The launcher that loads mods without touching your game folder.

  1. Go to github.com/garyttierney/me3/releases.
  2. Download me3_installer.exe from the newest release and run it.

The “Mod Engine 3 Manager” on Nexus is a different tool. Skip it.

2

Make a folder and fill it with three files

Make a folder at \games\nightreign-mods on whichever drive has about 12 GB free, for example E:\games\nightreign-mods. Not inside the Steam game folder, and not inside OneDrive. Then put these three files in it:

FileWhere fromOur version
More Map Variations .zipNexus 578, the Main file2.1.8.3
Seamless Co-op .zipNexus 31.1.3
Setup Nightreign Mods.batKen's GitHub—

Getting the script: on its GitHub page, click the download icon at the top right of the file view. Don't copy the text or use “Save as” on a raw link, because Windows can quietly save it as .txt.

How to check you got the right one: the version is in the filename. On MMV's Files tab, grab the Main file (about 4 GB). Its name looks like More Map Variations 578 2.1.8.3 2026-08-26T22-19Z ….zip. Leave the Weapons Mod Merge under Optional files alone for now; see Weapons upgrade. The Seamless one should have 1.1.3 in its name the same way.

Nexus needs a free account. Don't unzip anything; the script does that. If we ever move to newer versions, Ken says so in The Terror of Tana.

Heads-upThe MMV team no longer officially supports Seamless. They've moved to their own Server Redirector. Seamless is what we use and it works for us, but don't take bug reports to the MMV team while running it.
3

Close the game, double-click Setup

Double-click Setup Nightreign Mods.bat and let it run. It:

  • backs up your save into Save Backups in that folder
  • unpacks both mods and puts Seamless where MMV expects it
  • writes our shared launch file, the one that skips MMV's Server Redirector (loading that alongside Seamless crashes the game)
  • copies your relics and unlocks into the Seamless save, unless you already have one
  • puts a Nightreign (Modded) shortcut on your desktop

At the end it prints two version lines. Paste them in The Terror of Tana on LINE so we can see we match.

Windows warningIf Windows says “Windows protected your PC”, click More info → Run anyway. It does that for any script that came from the internet. The file is plain text, and you can open it in Notepad to read every line.
4

Play

  1. Open Steam (signed in, not in offline mode).
  2. Double-click Nightreign (Modded) on your desktop.
  3. One of us hosts and invites the others through Steam.

Launching Nightreign from Steam still gives you the normal, unmodded game with your normal save.

All four of us at once? Seamless allows up to 6 players. Nightreign itself is balanced for three, so in a four-player run, the extra scaling comes from Seamless rather than FromSoftware.

Doing it by hand instead
  1. Unzip More Map Variations into your folder. Inside you'll find a mod folder next to a .me3 file.
  2. Unzip Seamless Co-op somewhere else and move only its SeamlessCoop folder into MMV's mod folder.
  3. Next to MMV's own .me3 file, create MMV_Seamless.me3 with exactly this text. Turn on “File name extensions” in Explorer first, so it isn't secretly .me3.txt.
MMV_Seamless.me3
profileVersion = "v1"
start_online = false

[[supports]]
game = "nightreign"

[[packages]]
id = "MMV"
path = 'mod'

[[natives]]
path = 'mod/SeamlessCoop/nrsc.dll'
load_early = true

To carry your progress over, close the game and run this in PowerShell. It only copies; it never overwrites an existing Seamless save.

PowerShell
Get-ChildItem "$env:APPDATA\Nightreign" -Directory | ForEach-Object { $s = Join-Path $_.FullName 'NR0000.sl2'; $c = Join-Path $_.FullName 'NR0000.co2'; if ((Test-Path $s) -and -not (Test-Path $c)) { Copy-Item $s $c; "Copied: $c" } }

Then launch with MMV_Seamless.me3, never MMV's own .me3.

Every timeEach session

When Ken says “update”

Download the new zip(s) into the same folder and double-click Setup again. It replaces the old install, keeps your Seamless save, and makes a fresh save backup first. It uses the newest zip of each. Keep your zips in the folder: Setup needs them whenever it runs, and it never switches between plain MMV and Weapons without asking.

Running Setup again with the same zips is always safe. It reinstalls the same version, makes a fresh save backup, never overwrites your Seamless save, and rebuilds the shortcut. Use it as the fix-everything button.

On hold · ready when we areWeapons upgrade

The MMV team publishes an official More Map Variations and Weapons Mod Merge build. It's MMV plus TerraMag's Dark Souls 3 and Shadow of the Erdtree weapons and talismans. TerraMag is on the MMV team, and it's the only add-on they support. We're staying on plain MMV for now, and we'll switch together if we decide to.

Safe to pre-downloadHaving the Weapons zip in your folder changes nothing by itself. When Setup finds both zips, it asks before switching, and pressing Enter keeps whatever you're on.

Switching (everyone at once)

New Setup neededSwitching only works with the Setup from 25 Oct or later. Older copies can't ask, and they don't know which build you're on. Download Setup again from Ken's GitHub and replace the one in your mods folder. The new one shows Setup version 2026-10-25 under its title when it runs.
  1. Close the game and download More Map Variations and Weapons Mod Merge (Nexus 578, Optional files, 2.1.8.3, about 4 GB) into your mods folder. Leave the plain MMV zip and the Seamless zip where they are. If you deleted them after your first setup, download them again too: Setup needs all three.
  2. Double-click Setup. When it asks “Switch to MMV + Weapons?”, press Y.
  3. The version line now starts with MMV + Weapons. Post it in The Terror of Tana.

Switching back

Double-click Setup and press Y at “Switch BACK to plain MMV?”. Your Seamless save carries over both ways. Weapons only exist during a run, so nothing gets stuck in the save.

Heads-up: on 16 Oct the weapons mod fixed a bug where players could die endlessly in multiplayer. The merge build is from 27 Aug and may not include that fix yet.

When the night bitesTroubleshooting

“host is not using seamless co-op” / “host version … does not match”Someone's on a different MMV build (plain vs Weapons) or Seamless version, or used a different launch file. Compare the version lines everyone pasted, re-download the odd one out and run Setup again.
“Method SignIn is not available”The launch file got changed. Run Setup again to rewrite it.
Game opens but it's vanilla, no new bossesYou launched from Steam. Use the Nightreign (Modded) shortcut.
Shortcut does nothingme3 isn't installed properly. Re-run me3_installer.exe from step 1.
FromSoftware patched NightreignCelebrate, then launch from Steam and play the new official content. The modded setup can wait until MMV and Seamless catch up.
Setup says “STOPPED”Read the line after it. It tells you exactly what's missing, and nothing was changed.
Console window flashes and closesSteam isn't running.
Seamless loads but never connectsUpdate me3 (it needs v0.6.0 or newer). Last resort: change start_online to true.
Random crashesFolder is inside OneDrive, or the Server Redirector got loaded. Move the whole folder somewhere else and run Setup again.
My relics are goneYou're on an empty Seamless save. Delete NR0000.co2 from %APPDATA%\Nightreign\<your Steam ID> (or move it out), then run Setup again to copy your normal save across.
Everdark bosses missingSeamless pulls the Everdark rotation from GitHub. Check that GitHub isn't blocked on your network.

Still stuck? The MMV team doesn't answer in Nexus comments. They answer in their Discord, linked on the mod page.

Your machine, your callOptional extras

None of these change balance, and none of them have to match across the group. Get the main setup running first, then add one at a time and test it solo. Running Setup again replaces the MMV folder and the launch file, so re-add extras after every update.

Unlock the 60 fps cap

UnlockTheFps (Nexus 25). Put its folder inside mod\, then add this to the end of your launch file:

Add to MMV_Seamless.me3
[[natives]]
path = 'mod/UnlockTheFps/UnlockTheFps.dll'

The mod page says it supports Seamless. Its instructions are written for a different loader, so the snippet above isn't confirmed working. Last updated July 2025. Test solo

Ultrawide monitor fix

Nexus 35 removes the black bars. It's built for me3 and works with Seamless. Cutscenes and loading screens can show the world behind them. Only matters if you're on a 21:9 screen.
